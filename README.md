# Urban Environmental Analysis Automation

An ongoing academic project focused on analyzing urban environmental conditions using geospatial and open-source data.

## Project Overview

This project aims to develop a grid-based environmental analysis framework by integrating multiple urban and environmental indicators.

Current areas of analysis include:

- Air quality (PM10)
- Land Surface Temperature (LST)
- Vegetation indices (NDVI)
- Population distribution
- Geospatial data processing

The project uses satellite imagery, environmental monitoring data, population datasets, and spatial analysis techniques to investigate environmental conditions at the urban scale.

## Current Work

The project is currently under active development. Current work focuses on:

- Processing and quality-checking PM10 monitoring station data
- Spatial analysis of population and environmental indicators
- NDVI and LST analysis using satellite-derived data
- Developing reproducible Python-based analysis workflows
